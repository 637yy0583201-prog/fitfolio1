# Fitfolio

Fitfolio 是一个无需登录的个人衣橱与穿搭管理网页。它是纯前端、单文件应用，单品、穿搭和图片都保存在当前浏览器的 IndexedDB 中。

## 功能

- 录入、编辑和删除衣物或配饰
- 按关键词、品类和季节筛选单品
- 从真实已录入单品创建穿搭方案
- 查看穿搭中的全部单品详情
- 将单品、穿搭、图片和备注导出为 JSON 备份
- 从 Fitfolio JSON 备份恢复数据
- 手机和电脑响应式布局

## 使用

直接双击 `index.html` 即可在浏览器中使用，也可以把仓库部署到任意静态网页托管服务。

数据只属于打开网页的浏览器和网址。更换手机、浏览器、域名或托管平台前，请先点击网页顶部的“导出备份”，再在新环境中点击“导入备份”。导入会覆盖新环境中现有的 Fitfolio 数据。

## 部署

此项目没有构建步骤和外部依赖。将仓库根目录作为静态网站目录，并把 `index.html` 作为入口文件即可。

GitHub Pages 可在仓库的 `Settings → Pages` 中选择从默认分支根目录发布。

## 隐私

- 仓库只包含应用源码，不包含任何衣橱数据。
- 衣物图片、价格、备注和存放位置不会自动上传到 GitHub。
- 导出的 `fitfolio-backup-*.json` 可能包含个人图片和备注，请妥善保管，不要提交到仓库。
- 项目不包含 Supabase 密钥、OpenAI Sites 项目 ID、发布凭证或个人账号信息。

## 数据兼容

请在修改项目前先阅读 [DATA-SCHEMA.md](DATA-SCHEMA.md) 和 [AGENTS.md](AGENTS.md)。为了让旧数据继续可用，不要随意修改 IndexedDB 数据库名称、对象仓库名称或备份格式。
